Part 2 · The question

What group do these matrices generate?

Suppose S⊆PGL2​(Q​) is a finite set of matrices.

What is ⟨S⟩?
The whole of part 2 is this question. Input: finitely many matrices with algebraic entries. Output: what the group is, and ideally a presentation.

Part 2 · The question

Classification Conjecture

Let k be a number field and G an absolutely simple k-algebraic group. Call a subgroup Γ≤G(k)

  1. algebraic if it lies in a proper Q-algebraic subgroup H(Q)⪇Resk/Q​G(k);
  2. geometric if Γ≤G(kv​) is discrete for some nontrivial valuation v of k;
  3. arithmetic if Γ is commensurable with G(A) for some subring A≤k.

Conjecture. Every subgroup is algebraic, geometric, or arithmetic.

The statement from the project description. Note it's a trichotomy for every subgroup, not just finitely generated ones.

Part 2 · For PGL₂

First observation

  • If Γ is finitely generated, then Γ≤PGL2​(A) for a finitely generated subring A⊆Q​.
  • A⊆Ok​[S−1] for some number field k and finite set of primes S.
  • A is a lattice: A≤L​Rr×Cs×∏p∈S​kp​.

Conclusion

Γ↷v∏​PGL2​(kv​)properly
Finitely generated means finitely many denominators, so everything lives in an S-integer ring, which embeds discretely in the product of its completions. So Γ acts properly on a product of hyperbolic planes, hyperbolic 3-spaces and trees.

For all of these spaces, finitely generated ⟹ finitely presented. (Scott core theorem)

Discrete at one place: H² (real), H³ (complex) or a locally finite tree (p-adic). Trees and H² have discreteness algorithms. For H³ it's a conjecture over Q-bar, and false for arbitrary PGL2(C). In all three cases finitely generated implies finitely presented; for 3-manifolds that's the Scott core theorem.

Arithmetic subgroups

The conjecture says: if Γ is neither algebraic nor geometric, it is commensurable with G(A).

  • But a lattice in PGL2​R×PGL2​Q2​.
