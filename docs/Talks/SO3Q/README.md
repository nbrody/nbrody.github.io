# SO₃(ℚ)

A fullpage.js talk using only the supplied outline. Four sections follow the title, with horizontal slides within each section. Section 4 contains only its supplied heading.

Open `index.html` directly or serve this directory. fullpage.js 4.0.20, MathJax, and the font are bundled locally.

Use the arrow keys or Space to proceed through the slides. The right-side dots switch sections; the bottom dots switch slides within a section. The Present button enters fullscreen where supported.

- `index.html`: the supplied text, divided into slides
- `script.md`: the original outline
- `app.js`: fullpage.js setup and navigation
- `style.css`: styling matched to the other talks

Website location: `docs/Talks/SO3Q/`.
