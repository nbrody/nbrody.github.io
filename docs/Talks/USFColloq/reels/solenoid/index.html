What you're seeing

A 3-adic integer x = a₀ + 3a₁ + 9a₂ + ⋯ is an endless string of digits 0, 1, 2. Sort by a₀, then a₁, then a₂, and the 3-adic integers ℤ₃ nest into disks inside disks: a Cantor set. That is the cut face.

Carry that Cantor set once around a circle and glue the end to the start after adding 1. The result is the solenoid Sol₃ = ℤ₃ × [0, 1] / (x, 1) ∼ (x + 1, 0). Adding 1 carries, so …222 + 1 = …000, and every disk comes back on top of another one.

Keep only k digits and you get the k-th tube: ℤ/3ᵏ glued the same way is one circle winding 3ᵏ times around. Each tube lies inside the last and winds 3 times around it, which is the inverse limit of circles under z ↦ z³. These are exactly the nested solid tori of the Smale–Williams map (θ, w) ↦ (3θ, λw + ½e^{iθ}), whose attractor is Sol₃.

Sol₃ is connected but not path-connected. A path can only move around the circle direction, so each path component is a line that winds forever without closing up, and every one is dense. All the ordinary integers lie on one such line: the bead's path runs through x, x + 1, x + 2, …

Sol₃ is also a compact group, the Pontryagin dual of ℤ[1/3].
