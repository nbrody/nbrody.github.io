Flow polynomial F(G, t)

What it counts. At an integer t = k, F(G, k) is the number of nowhere-zero k-flows: orient the edges and assign each a value from ℤk ∖ {0} so that flow in = flow out at every vertex. The count doesn't depend on the orientation you chose — or even on which abelian group of order k you use — so it's a genuine invariant of the graph, and it's a polynomial in k.

How it's computed — deletion–contraction. Pick any non-loop edge e; the flows on the contraction G/e split into those extendable with a nonzero value on e and those that would need zero, giving

F(G) = F(G/e) − F(G∖e)

  • bridge ⇒ F ≡ 0 — no flow can cross a bridge without leaking;
  • loop ⇒ factor (t − 1) — a loop carries any nonzero value;
  • no edges ⇒ F = 1 — the empty flow.

The recursion is exponential in general, so this tool also smooths degree-2 vertices (their two edges are forced to carry the same flow), splits into connected components (F multiplies), contracts parallel edges first, and caches repeated subgraphs.

Relation to the Tutte polynomial: F(G, t) = (−1)|E|−|V|+c T(G; 0, 1−t), with c the number of components. All arithmetic here is exact integer arithmetic, and the golden-ratio evaluations below are done exactly in ℤ[φ].

Golden identity

Tutte: for a planar cubic graph, F(G, φ+2) = φ|E|·F(G, φ+1)². Agol–Krushkal conjecture the identity characterizes planarity of cubic graphs (arXiv:1801.00502). A failure therefore certifies non-planarity (try the Petersen preset) — while a bridgeless cubic graph that passes the identity yet is genuinely non-planar would be a counterexample to the conjecture.
