The Mathematics
The Hopf fibration maps a 3-sphere S³ ⊂ ℂ² to a 2-sphere S² ⊂ ℝ³. Each point p ∈ S² corresponds to an entire circle (fiber) in S³. Under stereographic projection from 4D to 3D, these circles form interlocking circles in ℝ³ that fill space. Any two circles are linked exactly once. Rotating the hypersphere in 4D morphs these tori inside-out in a stunning topological dance!
