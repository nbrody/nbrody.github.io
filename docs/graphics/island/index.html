    Inside the distance field
    A signed field is negative inside and zero on the surface. We raymarch to that surface; adding sine waves deforms it. Displaced fields are distance estimates, so the marcher takes smaller steps. In the leaf stage, the crown volumes are replaced with oriented twig planes whose outlines are cut by 2D distance functions. Leaves are enlarged for visibility.
