A candidate needs the threshold number of neighbors in that same state. The most common eligible candidate wins; ties follow the generator order shown above. No eligible candidate? The cell stays put.

This is a generator-based extension of the cyclic rule. The state group is independent of the spatial lattice: all groups work on square and Eisenstein lattices.
