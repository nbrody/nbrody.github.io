Gyroid Smoke

Color caught in a curling field.

MIDI · play the smoke

Start empty. Notes add smoke that stays and fills the rectangle. Restart flow clears it; turn MIDI mode off for the original color field.

Pitch → color and position · velocity → bursts
Sustain → hold · mod wheel → curl · bend → light
Turn Synth sound off if your keyboard already makes sound.

Flow

Choosing a state restarts the flow (S cycles). Start hold eases the flow in so the shape dissolves gradually. Gaps stay empty, so MIDI notes can fill them.

Backward runs the flow in reverse: smoke gathers out of chaos into the start state, then flows on live (B cycles). Back and forth keeps assembling and dissolving. MIDI notes light but do not stir these modes.

Light & color

Color phase changes new smoke. In MIDI mode it enters with notes; otherwise it enters at the edges.
