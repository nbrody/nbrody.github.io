Controls & Shortcuts

2D Canvas

  • Drag vertices of the base polygon to deform the whole orbit live.
  • Drag empty canvas to pan; scroll or pinch to zoom toward the cursor.
  • Shift-drag or right-drag to rotate the view; double-click to reset view.

3D Tunnel

  • Drag to orbit around the nested polygon tunnel; scroll or pinch to dolly along depth.
  • Double-click to return to the leading layer.

Keyboard Shortcuts

  • Space — Play / Pause
  • ← / → — Step backward / forward
  • R — Reset polygon
  • 0 — Reset camera view
  • 3 — Toggle 2D / 3D mode
  • H — Collapse / expand controls panel
