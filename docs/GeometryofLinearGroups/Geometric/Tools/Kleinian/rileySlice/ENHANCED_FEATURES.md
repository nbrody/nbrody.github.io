# Riley Slice Interactive Viewer - Enhanced Version

## Overview

This is an enhanced interactive visualization of the Riley slice, a 2-dimensional parameter space of two-generator Kleinian groups with one parabolic generator. The visualization has been improved with comprehensive educational content and interactive features to explain what the different colored regions represent.

## What Was Added

### 1. **Comprehensive Explanation Page** (`explanation.html`)
   - Full mathematical background on the Riley slice
   - Explanation of the Farey tree and trace polynomials
   - Detailed descriptions of what each visual feature represents
   - Discussion of combinatorial types and Dirichlet domains
   - Guidance on how to explore the interactive viewer
   - Questions to explore for deeper understanding

### 2. **Interactive Info Panel** (Right side of viewer)
   - **About the Riley Slice**: Quick overview of what you're looking at
   - **What the Colors Mean**: Explanation of Farey fractions and region coloring
   - **Key Features**: Expandable section explaining:
     - Colored regions and their combinatorial meaning
     - Pleating rays (yellow curves where traces are real and ≥2)
     - Ray extensions (continuation into non-discrete regions)
     - Boundary curves (where traces equal ±2)
   - **Under Your Cursor**: Real-time display of:
     - Current parameter value (complex number)
     - Zoom level
     - Regional information
   - **Mathematical Background**: Expandable section with technical details about generators

### 3. **Farey Fraction Legend** (Bottom-right corner)
   - Visual legend showing the first ~12 Farey fractions
   - Color swatches matching the regions in the visualization
   - Labels identifying each fraction p/q

### 4. **Enhanced JavaScript Infrastructure** (`infoPanel.js`)
   - `setupInfoPanel()`: Initialize expandable sections
   - `updateHoverInfo()`: Track cursor position and display region info
   - `generateLegend()`: Create list of Farey fractions
   - `getRegionDescription()`: Describe combinatorial types
   - `hsv2rgb()`: Color conversion matching the shader
   - `rgbToHex()`: Format colors for display

## How to Use

### Interactive Features
- **Zoom**: Use mouse wheel or trackpad to zoom
- **Pan**: Click and drag to move around the parameter space
- **Hover**: Move cursor over regions to see coordinate info
- **Toggle Features**: Use left panel to show/hide:
  - Colored regions
  - Pleating rays
  - Ray extensions
  - Boundary curves
- **Change Depth**: Increase Farey tree depth slider for finer detail (computation is slower)
- **Change Parametrization**: Switch between classical ρ and symmetric z coordinates

### Learning Path
1. Start with the overview in the info panel
2. Expand "What do I see here?" to understand the features
3. Click "📖 Read Full Explanation" for comprehensive background
4. Zoom around the visualization to see self-similar structure
5. Toggle different features on/off to isolate specific structures
6. Check the Farey Fractions legend while exploring

## Mathematics Behind the Visualization

### The Riley Slice
Parameter space of groups generated by:
- A: parabolic (fixed point at ∞)
- B: hyperbolic (depends on parameter ρ)

### Discreteness Criterion
A group Γ(ρ) is discrete if and only if certain "cusp regions" exist - i.e., when trace polynomials Φ_{p/q}(ρ) satisfy |Φ_{p/q}| < 2.

### Farey Coloring
Each colored region corresponds to a specific subset of Farey fractions being "active" (having |Φ| < 2). The color hue encodes the "deepest" active fraction via its slope p/q in the Farey tree.

### Pleating Rays
On these curves, the trace is real and ≥2, indicating the group has a pleated surface structure - a surface glued along axes. These are geometrically special.

## Performance Notes

- Farey depth 5-6: Good performance on modern machines
- Farey depth 7+: Slower computation, larger shaders
- Shader recompilation happens when depth changes
- Real-time hover info has minimal performance impact

## References

The Riley slice was introduced by Evan James Riley and has been studied extensively in the theory of:
- Kleinian groups and hyperbolic geometry
- Schottky space and deformation theory
- Pleating coordinates and earthquake theory
- Farey tessellations and parameter space structure

Key related work by Keen, Series, and others established the connection between Farey tree structure and the combinatorics of Dirichlet domains.
