Matrix Generators

How it Works

The domain is built exactly in the Klein model, where walls are planes: a candidate wall is kept only if it cuts the current polyhedron. The certificate then checks Poincaré's conditions — face pairings, every edge cycle, cusp completeness — and that your generators are products of the pairings, so the verdict is about your group.
