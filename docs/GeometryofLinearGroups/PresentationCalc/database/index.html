Two-generator subgroups \Gamma = \langle g_1, g_2 \rangle \le \mathrm{PGL}_2(\mathbb{Q}) with both generators of height at most \log B, run through the Presentation Calculator’s four steps. The height is h(g) = \log \sigma_1(\tilde g) for the primitive integral representative \tilde g: half the displacement of the basepoint of \mathbb{H}^2 \times \prod_p T_p, with a tree edge at p counting \log p. Each pair is listed once up to swapping, inverting either generator, and conjugating by the Klein four-group that fixes the basepoint.
