Roots

A Pisot number is a real algebraic integer θ > 1 all of whose Galois conjugates lie strictly inside the unit circle. A Salem number is a real algebraic integer τ > 1 whose conjugates all lie on or inside the unit circle with at least one on it (so τ⁻¹ is a conjugate and the rest have modulus exactly 1). The plane is shaded by how fast Newton's method z ↦ z − p(z)/p′(z) converges; the basins of the conjugates tile ℂ in a fractal pattern. Click any point to watch its orbit find a conjugate.

Deep zoom. Below a height of about 10⁻², the picture is drawn by perturbation. One orbit Z₀, Z₁, … is computed in exact fixed-point arithmetic, and each pixel tracks only its offset δₙ = zₙ − Zₙ in single precision, using δₙ₊₁ = δₙ (δₙA + RₙB) / (p′(Zₙ) + δₙB), where Rₙ = Zₙ − Zₙ₊₁ and A = Σ (k−1) pₖ δₙᵏ⁻², B = Σ k pₖ δₙᵏ⁻² come from the Taylor coefficients pₖ of p at Zₙ. The large terms cancel exactly in this form, so a pixel keeps its full relative precision while it shadows the reference. Once it separates, it carries on with ordinary single-precision Newton steps.
