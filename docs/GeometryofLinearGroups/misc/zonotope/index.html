The hexa-grid toy was created by the Netherlands Mathematical Research Institute. The instruction manual includes a few claims, and this document provides proofs or partial proofs of these.

Much of this theory generalizes to higher dimension base polytopes $B$, and to other-type total polytopes $E$, for fiberings $\pi\colon E\to B$. The wealth of different perspectives one can view this object allows one to understand its properties via algebraic, topological, and combinatorial methods. Many of its properties are obscured from one perspective but obvious from another.

1The cube over the $2n$-gon

Let $C_n=[0,1]^n$ denote the unit cube, and $e_j$ the standard basis vectors. There is a map $\pi\colon C_n\to P_{2n}$, the regular $2n$-gon, given by $$e_j\mapsto v_j=\left(\cos\left(\frac{\pi (j-1)}{n}\right),\ \sin \left(\frac{\pi (j-1)}{n}\right)\right).$$

Starting from the origin $\mathbf{0}$ and traversing the vertices in the boundary of $P_{2n}$ counter-clockwise, we follow edges $v_1,v_2,\dots,v_n,-v_1,-v_2,\dots,-v_n$. We call $\sum_{i=1}^n v_i=\mathbf{1}$, and observe that this is the image of $(1,1,\dots,1)$ under $\pi$.

2Paths and reduced words

The “lower path” $p_0$ from $\mathbf{0}$ to $\mathbf{1}$ is labeled $12\dots n$, and the “upper path” $p_1$ is labeled $n\dots 21$. We can interpret these paths as elements of the symmetric group $\Sym_n$, where the reading word obtained by traversing edges of a shortest path from $\mathbf{0}$ to $\mathbf{1}$ is the one-line notation of the permutation.

Let $s_i$ be the transposition $(i,i+1)\in\Sym_n$ for $1\leq i<n$. An $S$-factorization of $w\in \Sym_n$ is a minimal-length way of writing $w$ as a product of $s_i$s. Two factorizations $\w_1,\w_2$ are in the same commutation class if one can be obtained from the other by exchanging commuting generators in the factorization. With respect to the generators $s_i$, we have the presentation $\Sym_n=\langle s_1,\dots,s_{n-1}\mid (s_is_j)^{m_{ij}}\rangle$, where $$m_{ij}=\begin{cases}1 &\text{if }i=j, \\ 2&\text{if }|i-j|\geq2, \\ 3&\text{if }|i-j|=1.\end{cases}$$ Thus, we have for example, $s_1s_3s_4 \sim s_3s_1s_4 \sim s_3s_4s_1$.

A tiling determines a class of path-of-paths from $p_0$ to $p_1$, which we can interpret as a commutation-equivalence class of factorizations of $w_0=(n,n-1,\dots,2,1)$.

Note that when we apply $s_1$ to the path $p_0$, we obtain the path $(2,1,3,\dots,n)$, which travels in directions $v_2,v_1,v_3,\dots$ in that order. Write $p_w$ for the path whose reading word is $w(1)w(2)\cdots w(n)$. Letting $\Sym_n$ act on $\mathbb R^n$ by permuting coordinates, $(w\cdot x)_k=x_{w(k)}$, we have the relation $wp_0=p_{w^{-1}}$, and more generally, $u^{-1}p_v=p_{uv}$.

An ascent in a path $p_w$ at position $j$, that is $w(j)<w(j+1)$, corresponds to two adjacent edges which form a parallelogram on the side of $p_w$ facing $p_1$. Thus, we can increase the number of inversions by pushing the path across this parallelogram by applying $s_j$, replacing $p_w$ with $p_{ws_j}$. So long as there is some ascent in the word, there is an adjacent ascent, and thus we can apply some $s_j$ and get a path closer to $p_1$. This can be seen as moving up in the weak order by a covering relation.

3Tilings are commutation classes

Proposition 1. Commutation classes of $S$-factorizations of $w_0=(n,n-1,\dots,1)$ are in bijection with tilings of $P_{2n}$.
Proof. Let $\w=i_1\dots i_r$ be a factorization of $w_0$, where we identify $i_j$ with $s_{i_j}$; let $w_j=i_1\dots i_j$. Consider the sequence of paths $(p_{w_j})_{j=0}^r$. This determines a tiling, since successive paths differ across a single parallelogram, namely we replace the subpath $v_{w_{j-1}(i_j)}v_{w_{j}(i_j)}$ with $v_{w_{j}(i_j)}v_{w_{j-1}(i_j)}$.

Two factorizations give the same tiling if and only if $\w$ and $\w'$ are commutation-equivalent. Given a tiling, we can read off a word $\w$ in the following way. Begin with the path $p_0$. It can have at most $n-1$ tiles left-adjacent to it, hence there is at least one tile it follows two consecutive edges of. This determines some simple reflection $s_{i_1}$ we can apply to get a path $p_{i_1}$ that follows the tiling. If there were two tiles it followed, then this corresponds to two distinct simple reflections that can be applied, which would have to have indices at least two apart, thus they commute in the symmetric group. So a tiling determines a reduced word with the only ambiguity being commutation class.

Conversely, if $\w$ and $\w'$ are commutation-equivalent, we can think of each word as building a tiling as described above. These only differ in the ordering that the tiles are placed, but they place the same tiles. ∎

4Braid moves and the word problem

Proposition 2. Any two reduced words $\w=s_1s_2\dots s_r$, $\w'=s_1'\dots s_r'$ for $w\in \Sym_n$ are related by 3- and 2-moves.
Proof. The result is clear for $r=1$. Now let $r>1$, and assume that the result is true for words with length less than $r$. If $s_1=s_1'$, then induction on $r$ implies the result for $s_1\w$ and $s_1\w'$. Otherwise, since $s_1$ and $s_1'$ are both prefixes for $w$, the fact that weak order for finite Coxeter groups is a join lattice (proved in Björner–Brenti) implies that $s_1\vee s_1'=\alpha_{1,1'}$ is a prefix for $w$, and hence there is some reduced word $\beta$ with $\alpha_{1,1'}\beta=w$. Here $\alpha_{1,1'}=s_1s_1'$ or $s_1s_1's_1$, according as $s_1,s_1'$ commute or not, and $\alpha_{1',1}$ is the same word begun with $s_1'$. By induction, applied after cancelling the common first letter, we have $\w\sim \alpha_{1,1'}\beta$ and $\alpha_{1',1}\beta\sim \w'$, while $\alpha_{1,1'}\beta$ and $\alpha_{1',1}\beta$ differ by a single 2- or 3-move. This proves the claim. ∎

5Counting tilings

The enumeration of commutation classes of $S$-factorizations of $w_0$ can be done on a computer. A rough algorithm goes as follows. We can begin with some fixed reduced factorization $\w$, and build a graph $\Gamma_w$ recursively in the following way. The first word $\w$ is a vertex, and for each 3-move we can apply to $\w$, we add a new vertex and a blue edge connecting them. For each 2-move we can apply, we add a new vertex and a red edge connecting them. Now repeat this process for each of the new vertices, but if the word obtained from a move has already been seen, we do not add a new vertex but connect it to the corresponding present vertex with the appropriate color.

The preceding proposition amounts to the fact that this graph will eventually include every reduced word for $w$, and all of the 2- and 3-adjacent words will be represented with edges. Now we list the lexicographically first vertex in each red-equivalence class, and count them.

6Lines in general position

Proposition 3. There is a bijection between the combinatorial structure of $n$ lines in general position in the plane and tilings of the $2n$-gon which are (realizable) oriented matroids.
Proof. Consider a collection of $n$ lines in general position in the plane. There are $\binom{n}{2}$ distinct intersection points, and we may draw a large circle which contains all of the intersection points in its interior. The lines intersect this circle in $2n$ points, and we may choose an arbitrary arc between these to be the $\mathbf{0}$-component. We now traverse the circle counter-clockwise, labeling each line with numbers $1$ through $n$ as we pass them. For each line, record the order in which it crosses the other lines. This determines the structure of the hyperplane starting from edge $i$ of the regular $2n$-gon, for the line labeled $i$. ∎

In the example below, since line 3 crosses lines 1, 2, 4, 5, then 6, we obtain the tiling where the green hyperplane in the cube complex passes through squares whose edges are parallel to $13, 23, 34, 35,$ and $36$. This perspective gives a labelling of each parallelogram by a pair $ij$ of the parallelism class of its edges.
