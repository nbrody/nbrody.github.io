texcast

Animated LaTeX, stored as text. A recording is just the formulas and when they appear. The player typesets them in your browser and morphs each one into the next, the way asciinema replays a terminal.

  • TinyThe whole animation above, as a text file. That's smaller than a single thumbnail image.
  • Real typePause and select it, zoom in as far as you like. It stays sharp and follows dark mode.
  • EditableSpot a typo? Change one line of the file. Nothing to re-render or re-upload.

Steps or keystrokes

A derivation stores one line per step. A typing recording stores every keystroke as a small edit, and can show the source as it's typed. While the LaTeX is half-finished, the last version that parses stays on screen.

The format

Like asciinema's .cast files: JSON lines. The first line is a header, and each line after it is an event. An event's first number is the delay in seconds since the previous event.

# completing-the-square.texcast
{"version": 1, "title": "Completing the square", "morph": 0.8}
[0,   "show",    "x^2 + 6x + 5 = 0"]
[0,   "caption", "Move the constant over."]
[2.5, "show",    "x^2 + 6x = -5"]
[2.5, "caption", "Add $9$ to both sides."]
[0,   "show",    "x^2 + 6x + \\blue{9} = \\blue{9} - 5"]
[2.5, "show",    "(x + 3)^2 = 4"]
[dt, "show", latex]Replace the formula. Matching symbols glide to their new places, the rest fade.
[dt, "edit", pos, del, text]Delete del characters at pos and insert text. The keystroke recorder writes these.
[dt, "caption", text]Set the caption. $…$ is inline math, and "" clears it.
Headertitle, morph (seconds per transition), hold (seconds on the last frame), source (show the LaTeX), poster (seconds, or "end"), size (type scale), macros.
Colours\blue{…} \red{…} \green{…} \gold{…} \purple{…} \faint{…}. They follow light and dark mode, and colour changes animate too.

Lines starting with # are comments. Backslashes are doubled because each line is JSON. The recorder writes the file for you, so you rarely type them by hand.

Put one on a page

One script tag. It loads KaTeX if the page doesn't already have it.

<script src="texcast/player.js"></script>
<texcast-player src="derivation.texcast" autoplay loop></texcast-player>

Click a player, then use Space to play or pause, ← → to step through, and Home End to jump to either end. Stepping with the arrow keys works well for presenting a derivation live.
