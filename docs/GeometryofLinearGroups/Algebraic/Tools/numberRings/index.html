Input syntax and what is computed

The field is \mathbb{Q}[x]/(f) for an irreducible f \in \mathbb{Q}[x]; any single letter may name the root in the element boxes. Use + - * / ^ and parentheses; juxtaposition multiplies (3a), and negative powers invert (a^-1).

Everything is exact. The ring of integers comes from the Round 2 algorithm. S is the set of primes of the generated field at which some generator has a pole. The page reports the integral closure \mathcal{O}_{S} of R, the index [\mathcal{O}_{S} : R], and the order R \cap \mathcal{O}. From these, R = (R \cap \mathcal{O})[1/s] for any s whose prime divisors are exactly S.
