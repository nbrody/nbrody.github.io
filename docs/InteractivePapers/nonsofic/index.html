A Non-Sofic Group

A counterexample to the soficity conjecture

Theorem. The unit group $L_{\mathbb{F}_2}(1,2)^\times$ of the binary Leavitt algebra is not sofic.

From Ten Advances in Mathematics and Theoretical Computer Science (OpenAI), Chapter 3 — extracted chapter (PDF)

What is a sofic group?

A countable group $H$ is sofic if finite pieces of its multiplication table can be almost-faithfully modeled by permutations of a finite set: maps $p_n\colon H \to \mathrm{Sym}(Y_n)$ with

$$p_n(1)=1,\qquad d_H\big(p_n(gh),\,p_n(g)p_n(h)\big)\to 0,\qquad d_H\big(p_n(g),1\big)\to 1 \ (g\neq 1)$$

where $d_H$ is normalized Hamming distance: multiplication holds at almost every point, and every nonidentity element moves almost every point.

The soficity conjecture

  • Gromov (1999) introduced the approximation property in symbolic dynamics; Weiss (2000) named sofic groups and asked: is every countable group sofic?
  • Residually finite groups, amenable groups, LEF groups, and many more are sofic — for 25 years no counterexample was known.
  • Soficity implies Gottschalk surjunctivity, Kaplansky direct finiteness (over fields), the determinant conjecture, ...
Question (now settled). Does a non-sofic group exist? — Yes.

The star of the show

The binary Leavitt algebra over $\mathbb{F}_2$:

$$R = L_{\mathbb{F}_2}(1,2) = \mathbb{F}_2\langle s_0,s_1,t_0,t_1 \mid t_i s_j = \delta_{ij},\ s_0 t_0 + s_1 t_1 = 1\rangle$$
  • $t_0 s_0 = 1$ but $s_0 t_0$ is a proper idempotent — one-sided inverses.
  • $R \cong R^2$ as right $R$-modules: binary self-similarity.
  • $R$ is countable; its unit group $R^\times$ is the non-sofic group.

Prefix codes and self-similarity

A complete prefix code $E=(a_1,\dots,a_q)$: pairwise prefix-incomparable binary words whose cylinders $[a_i]$ partition the boundary of the binary tree. Each such code gives a unital ring isomorphism

$$\Theta_E\colon M_q(R) \xrightarrow{\ \sim\ } R,\qquad (r_{ij}) \mapsto \sum_{i,j} s_{a_i}\, r_{ij}\, t_{a_j}$$

So $R$ contains matrix algebras over itself of every size — the engine that lets small groups be conjugated into corners.

Cast of characters

The nine-leaf code $D = (\alpha_1,\alpha_2,\alpha_3,\beta_1,\beta_2,\beta_3,\nu_1,\nu_2,\nu_3)$ with blocks

$$\alpha = (000,001,01),\qquad \beta = (1000,1001,101),\qquad \nu = (1100,1101,111)$$
  • $G = \mathrm{EL}_D(R) \cong \mathrm{EL}_9(R)$ — elementary group, has property (T) (Ershov–Jaikin-Zapirain).
  • $\Gamma = \mathrm{EL}_\alpha(R) \cong \mathrm{EL}_3(R) \le G$ — acts only inside $[0]$, also property (T).
  • $J = V_{1000} \cong V$ — a copy of Thompson's group $V$ acting only inside $[1000]$.

Thompson's group $V$

Elements of $V$: bijections of infinite binary strings given by prefix replacement between two complete codes, $a_i\omega \mapsto b_i\omega$. Realized in $R^\times$ by

$$U_g = \sum_{a\in E} s_{g(a)}\, t_a,\qquad U_h U_g = U_{h\circ g}$$
  • $V$ is finitely presented, infinite, and simple.
  • Hence $V$ is not LEF (locally embeddable into finite groups): a finitely presented LEF group is residually finite, but an infinite simple group has no finite quotients.
  • This is the contradiction the whole proof aims at.

Input 1: Kun's expander decomposition

Theorem (Kun). For a property-(T) group, the generator graph of any sofic approximation becomes a disjoint union of uniformly expanding graphs after editing $o(|Y_n|)$ edges.

Uniform expansion constant $\gamma$ — but possibly many components: disjoint copies of a sofic approximation are still a sofic approximation.

Input 2: the Kun–Thom obstruction

Theorem (Kun–Thom). If $K$ has property (T), $J$ is finitely generated, and $K\times J$ has a sofic approximation whose $K$-generator graph is a single uniform expander on the whole set, then $J$ is LEF.

The single-expander hypothesis is essential:

$\Lambda = SL_3(\mathbb{Z})$ (property (T), sofic) and $B = BS(2,3)$ (sofic, not LEF), yet $\Lambda\times B$ is sofic. Many expanding $\Lambda$-components cannot force $B$ to be LEF.

The new bridge: expander matching

Proposition 2.3. Let $\Gamma \le G$ be infinite f.g. property-(T) groups with $$G = \langle \Gamma, t_1,\dots,t_m\rangle,\qquad t_i\,\Gamma\,t_i^{-1} \le \Gamma,$$ and let $J \le G$ be finitely generated with $$[\Gamma,J]=1,\qquad \Gamma\cap J = \{1\},\qquad t_1\,J\,t_1^{-1} \le \Gamma.$$ Then soficity of $G$ forces $J$ to be LEF.

The extra nesting — one conjugation compresses both commuting factors into $\Gamma$ — is exactly what the $SL_3(\mathbb{Z})\times BS(2,3)$ example lacks.

How the matching works

  1. Run Kun's theorem twice: $\Gamma$-components $\mathcal{Q}$ and $G$-components $\mathcal{A}$ of the same finite set.
  2. Since $t_i\Gamma t_i^{-1}\le\Gamma$, each transported component $\tau_i C$ lands almost inside some $\Gamma$-component $Q$.
  3. Median trick: $f(z) = \frac{M(z)}{M(z)+m_A}$ (component size, normalized by an ambient median) is almost nondecreasing under every generator; permutations conserve the total, so expansion pins $f \approx \tfrac12$ — matched components have nearly equal sizes.
  4. A transported component fills $>\tfrac12$ of its target, so the matching is injective.
  5. Conjugating back by $\tau_1^{-1}$: the $J$-generators preserve the $\Gamma$-components. Select one good component, repair the actions — a sofic approximation of $\Gamma\times J$ on a single expander. Kun–Thom applies.

Realizing the hypotheses in $R^\times$

Two prefix replacements $u,v \in V \le G$, with $\zeta = (100,101,11)$ partitioning $[1]$:

$\alpha_i$ $\beta_i$ $\nu_i$
$u$ $\alpha_i 0$ $\alpha_i 1$ $\zeta_i$
$v$ $\alpha_i 0$ $\zeta_i$ $\alpha_i 1$
$$u\Gamma u^{-1} = v\Gamma v^{-1} = \mathrm{EL}_{(\alpha_1 0,\alpha_2 0,\alpha_3 0)}(R) \le \Gamma,\qquad uJu^{-1} = V_{0001} \le \Gamma,\qquad G = \langle \Gamma, u, v\rangle$$

$\Gamma$ lives on $[0]$, $J = V_{1000}$ on the disjoint cylinder $[1000]$; $u$ carries $J$ into $[0001] \subseteq [0]$.

Endgame

  1. Suppose $G = \mathrm{EL}_D(R)$ were sofic.
  2. Proposition 2.3 (with $t_1 = u$, $t_2 = v$) forces $J$ to be LEF.
  3. But $J \cong V$ is finitely presented, infinite, simple — not LEF. Contradiction.
  4. So $G$ is not sofic; soficity passes to subgroups, and $G \le R^\times$, so:
Theorem. $L_{\mathbb{F}_2}(1,2)^\times$ is not sofic.

What remains open

  • Hyperlinearity: is $R^\times$ hyperlinear? No non-hyperlinear group is known (Connes's embedding conjecture for groups).
  • Surjunctivity: if $R^\times$ is surjunctive, it is a surjunctive non-sofic group; if not, Gottschalk's conjecture fails.
  • Determinant & algebraic eigenvalue conjectures for $R^\times$.
  • Kaplansky direct finiteness for $k[R^\times]$ in positive characteristic.

Related: the Aldous–Lyons conjecture was disproved by Bowen–Chapman–Lubotzky–Vidick; soficity is its restriction to invariant random subgroups concentrated on a single normal subgroup.
