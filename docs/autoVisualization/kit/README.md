# AutoViz kit

The shared design system and library behind every AutoViz page. Plain scripts, no
dependencies, no network. Load `av.css` and `av.js`, then only the modules a page needs:

```html
<link rel="stylesheet" href="../kit/av.css">
<script src="../kit/av.js"></script>      <!-- core: always -->
<script src="../kit/draw.js"></script>    <!-- canvas drawing: almost always -->
```

| module | global | what it gives you |
|---|---|---|
| `av.js` | `AV.page`, `AV.test`, colour + format helpers | the page shell (below) |
| `draw.js` | `AV.clear/label/dot/ring/line/arrow/polyline/grid/camera` | 2D drawing in CSS px; a y-up world camera |
| `plot.js` | `AV.plot`, `AV.ticks` | quiet charts inside a pane |
| `linalg.js` | `AV.la` | vectors, matrices, `jacobi` eigen, `cholesky`, `gramSchmidt`, frames in ℝⁿ, `orderOf` |
| `exact.js` | `AV.ex`, `AV.Q` | BigInt gcd/primes/factor/σ, exact rationals, continued fractions, Farey, Stern–Brocot, 2×2 integer matrices |
| `complex.js` | `AV.cx`, `AV.mob` | complex numbers `[re, im]`, Möbius maps (∞ = `null`), fixed points, kinds, circle images |
| `hyperbolic.js` | `AV.hyp` | disk / half-plane geodesics, polygons, circles, distance, Cayley transform, disk isometries (needs `complex.js`) |
| `space3d.js` | `AV.orbit3d`, `AV.curves3d`, `AV.points3d` | 3D orbit camera; depth-cued curves and points on a 2D canvas |
| `gl.js` | `AV.gl` | WebGL2 programs, full-screen quad, pane viewports, textures, GLSL palette snippets |
| `tex.js` | `AV.tex`, `AV.texify`, `AV.texLabels` | typeset mathematics with the vendored KaTeX in `vendor/katex/` (no network) |

Working references: `../days/2026-11-09-euclid-gets-stuck.html` (ray-marched WebGL2 stage, typeset labels,
exact arithmetic, an inset second view), `examples/split-panes.html` (panes + chart + hyperbolic),
`examples/space3d.html` (3D), `examples/shader.html` (WebGL2), and
`../days/2026-09-29-coxeter-plane.html` (single stage, linalg, tour choreography).

## `AV.page(options)` → `app`

```js
const app = AV.page({
  title: 'The Coxeter Plane',                 // ≤ 7 words
  hook: 'Every finite reflection group hides one plane where it is simply a rotation.',
  date: '2026-09-29',
  credit: 'generated by Claude (Opus 5.5)',   // footer of the info sheet
  hint: 'drag to tilt · tap a root',          // gesture hint above the dock; fades on first touch
  stage: '2d',                                // '2d' (default) | 'webgl2' | 'svg'
  panes: [{ id: 'disk', weight: 3 }, { id: 'plot', weight: 2, label: 'circumference' }],  // optional
  split: 'auto',                              // 'auto' (row when wide, column on phones) | 'row' | 'column'
  controls: [ /* see below; ≤ 4 besides play */ ],
  tour: [{ text: 'One sentence…', enter: app => { /* set state, start motion */ } }],  // 3–5
  math: `<p>The exact theorem…</p><p class="ref">Author Year.</p>`,
  setup: app => {},                           // once, after the first layout (e.g. compile shaders)
  step: (dt, app) => {},                      // every frame while playing (dt in seconds)
  draw: app => {},                            // whenever something changed
  live: false,                                // true: draw every frame even when idle
  autoplay: true,                             // start playing if there is a play control
  posterStep: 0,                              // tour step used for thumbnails and the gallery embed
  posterDelay: 1600,                          // ms to let motion settle before the thumbnail
  edgeScrim: false,                           // darken top/bottom edges behind the chrome (bright stages)
  overlay: false,                             // extra 2D canvas above the stage (automatic for webgl2/svg)
});
```

### Controls

```js
{ type: 'play' }                                              // play/pause; Space toggles it
{ type: 'segmented', id: 'sys', value: 'E8', options: [{ value: 'E8', label: 'E<sub>8</sub>' }, …], onChange: (v, app) => {} }
{ type: 'slider', id: 'r', label: 'r', min: 0, max: 4, step: 0.01, value: 1, format: v => AV.fmt(v, 2), onChange }
{ type: 'toggle', id: 'orbit', label: 'orbit', value: true, onChange }
{ type: 'button', id: 'c', label: 'apply <i>c</i>', key: 'c', primary: true, title: 'tooltip', onClick: app => {} }
{ type: 'button', id: 'snap', icon: 'reset', title: 'Reset view', verify: false, onClick }   // icons: reset step shuffle play plus minus
```

`app.get(id)`, `app.set(id, value, { silent })` (fires `onChange` unless silent),
`app.press(id)`, `app.pulse(id)` (draws the eye to a control during a tour step).

### The app

| | |
|---|---|
| `app.ctx` / `app.gl` / `app.svg` / `app.octx` | drawing surfaces (CSS-pixel transform already applied to `ctx`/`octx`) |
| `app.W`, `app.H`, `app.dpr` | viewport size in CSS px, device pixel ratio |
| `app.fitCircle(margin)` → `{x, y, r}` | largest circle clear of the chrome (single-stage pages) |
| `app.fitRect(aspect, margin)` → `{x, y, w, h, cx, cy}` | largest rectangle of that aspect clear of the chrome |
| `app.panes`, `app.pane(id)` | pane rects `{x, y, w, h}` with `.fitCircle()`, `.fitRect()`, `.contains(p)` |
| `app.clip(pane, fn)` | draw clipped to a pane |
| `app.onResize(fn)` | recompute geometry (never reset maths state here) |
| `app.readout(html)` | the live check, top right. Use `AV.ok(bool)`, `<span class="big">`, `<span class="k">label</span>`, `<small>` |
| `app.legend([{ color, label, line }])` | tiny legend under the readout (≤ 4 items, ≤ 2 words each) |
| `app.tween(ms, u => …, { ease, key })` → Promise | animate; a new tween with the same `key` cancels the old one |
| `app.busy()` | any tween running |
| `app.after(ms, fn)`, `app.every(ms, fn)` | timers cancelled automatically when the tour step changes |
| `app.play()`, `app.pause()`, `app.toggle()`, `app.playing` | playback |
| `app.goto(i)`, `app.stepIndex` | tour navigation (← → keys) |
| `app.pointer({ down, drag, up, tap, dbl, hover, leave, wheel })` | `p = {x, y, pane}`; `drag(p, {dx, dy})`; taps are presses that moved < 4 px |
| `app.cursor('grab')`, `app.redraw()`, `app.info(open)`, `app.relayout()` | misc |
| `app.mode` | `'full'`, `'embed'` (gallery hero: stage only) or `'poster'` (thumbnail capture) |

### Self-tests

```js
AV.test('E₈ has 240 roots', () => roots.length === 240 || 'got ' + roots.length);
```

Return `true` to pass; return a string (the explanation) or `false`, or throw, to fail.
Tests run once after load; results are logged and read by `tools/verify.mjs`.

## Mathematics is typeset (`tex.js`)

Every mathematical symbol on a page is set with KaTeX, never with Unicode stand-ins
(no `ℚ(√−5)`, `g₁`, `x²` in a UI font). Load the vendored copy, then `tex.js`:

```html
<link rel="stylesheet" href="../kit/vendor/katex/katex.min.css">
<script src="../kit/vendor/katex/katex.min.js"></script>
<script src="../kit/tex.js"></script>
```

- `AV.tex(src)` → an HTML string (cached). Use it wherever the kit takes HTML: `app.readout`,
  a slider's `format` or `label`, legend labels.
- `AV.texify(html)` → the string with every `$…$` typeset. Wrap tour captions and the `math`
  sheet in it. Keep `title` and `hook` free of formulas (the gallery shows them as plain text).
- `const labels = AV.texLabels(app)` → an HTML layer above the stage for labels pinned to stage
  positions. Each frame call `labels.set([{ key, x, y, tex, color, size, align, valign }])`
  with the whole set; labels whose key is missing disappear. Use it instead of `AV.label`
  whenever the label is a formula.
- A formula counts toward the word budgets by its letters and numbers, so keep captions light.

Reference: `../days/2026-11-09-euclid-gets-stuck.html`.

## Look and feel

- Colours: `AV.C.{bg, ink, ink2, muted, accent, amber, rose, blue, violet, green, cream, sky}`;
  categorical `AV.PALETTE` (use ≤ 4); sequential `AV.ramp(t, 'aurora' | 'ember' | 'ice' | 'diverge')`
  returns `[r, g, b]` → `AV.rgba(c, alpha)`; `AV.mix(a, b, t)` mixes in OKLab.
  In shaders put `//#AV` in the fragment source to get `av_ramp`, `av_cycle` (cyclic, for phases)
  and the palette constants.
- Numbers: `AV.fmt(x, digits)` (true minus, trimmed), `AV.int(n)` (thin-space groups),
  `AV.sub(12)` → ₁₂, `AV.sup(-1)` → ⁻¹. Math text in captions: `<i>` renders serif italic,
  `<b>` renders in the accent colour.
- Drawing: hairlines (0.6–1.5 px), dots 2–4 px, glow sparingly (`{ glow: 4 }` on one focal
  object), `AV.label` for the few on-canvas words, `globalCompositeOperation = 'lighter'`
  for dense line fields.
- CSS tokens live on `:root` in `av.css` (`--av-*`); the gallery uses the same tokens.
