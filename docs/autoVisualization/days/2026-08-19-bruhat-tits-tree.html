The Bruhat–Tits Tree for SL2(ℚp)

Serre's tree Xp has one vertex for each homothety class of ℤp-lattices in ℚp², with [L] and [L′] joined when representatives can be chosen with L ⊃ L′ ⊃ pL; since the index-p sublattices of L correspond to the lines of L/pL ≅ 𝔽p², the result is the (p+1)-regular tree, and GL2(ℚp) acts on it by isometries. Every vertex below is an honest lattice, computed as an exact integer matrix; each is shaded by its displacement d(v, gv), a convex function on the tree whose minimum is the translation length ℓ(g) = |vp(λ1) − vp(λ2)|, read off the Newton polygon of the characteristic polynomial. For g ∈ SL2(ℚp) this says g is elliptic — fixing a vertex, so the highlighted set is a whole subtree — exactly when tr g ∈ ℤp, and otherwise hyperbolic, translating along an axis by ℓ(g) = −2vp(tr g).
