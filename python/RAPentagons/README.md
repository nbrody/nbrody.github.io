# Right-angled polygon reflection search

This project searches for geometric representations of right-angled polygon
reflection groups in

\[
\mathrm{PGL}_2(\mathbb Z[S^{-1}]).
\]

It uses the trace-zero model

\[
R(x,y,z)=\begin{pmatrix}x&y\\z&-x\end{pmatrix},\qquad q(x,y,z)=x^2+yz.
\]

A primitive integral vector with `q(v)` an `S`-unit gives a reflection. Two
reflections meet at right angle exactly when

\[
B(v,w)=2xx'+yz'+zy'=0.
\]

A right-angled `n`-gon is a cyclic list of such vectors with adjacent
orthogonality and hyperbolic non-adjacent pairs:

\[
B(v_i,v_j)^2 > 4q(v_i)q(v_j).
\]

## Install

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

## Seed known examples

```bash
python -m ra_polygon_search.search --seed --primes 2,3 --sides 5
```

The seed database includes:

- a right-angled pentagon over `Z[1/6]`,
- a right-angled pentagon over `Z[1/10]`,
- a right-angled pentagon over `Z[1/15]`,
- a legacy `Z[1/2]` hexagon candidate is kept in `examples.py` for repair experiments; the validator does **not** seed it as a success because the listed order fails one adjacent orthogonality check.

## Run a search from the command line

```bash
python -m ra_polygon_search.search \
  --primes 2,5 \
  --sides 5 \
  --method orbit \
  --max-norm 100000 \
  --coord-bound 1000 \
  --max-vectors 100000 \
  --max-solutions 10 \
  --seed
```

Use `--method enumerate` for direct enumeration of primitive vectors with
`S`-unit norm. Use `--method orbit` for the conjugation orbit generated by

\[
T=\begin{pmatrix}1&1\\0&1\end{pmatrix},\quad
S=\begin{pmatrix}0&-1\\1&0\end{pmatrix},\quad
D_p=\begin{pmatrix}p&0\\0&1\end{pmatrix}.
\]

## Run the front end

```bash
streamlit run streamlit_app.py
```

The app lets you select denominator primes, polygon size, search bounds, and
vector-generation method. It stores successful configurations in
`outputs/solutions.sqlite` and summarizes the database.

## Notes

The current graph search is intentionally simple and transparent. The main
extension point is `ra_polygon_search/orbit.py`, where you can replace the
basic BFS by a more arithmetic finite-generating-set action on the relevant
integral orthogonal group or add stronger local pruning.
